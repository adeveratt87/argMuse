Argos Product Search: MCP connector

Read-only search and product details from the Argos (UK) catalogue, over the Model Context Protocol.

Overview

This connector lets an AI assistant help a customer find products sold by Argos in the UK and look up their details. It exposes exactly two tools:

  • search: find products by keywords. Returns product IDs, names, prices in GBP and product page links.
  • getProducts: full details for one product: name, link, plain-text description, price and any promotional badge code.

Both tools are read-only. The connector cannot add to a basket, check out, place orders or change any account. Product data comes live from Argos on every call; nothing is cached.

Example uses: “find me a cordless kettle under £30”, “what are the dimensions of product 8444015?”, “compare these two TVs”.

Connecting

MCP endpoint
https://argmuse.vercel.app/mcp
Transport
MCP Streamable HTTP (specification 2025-11-25), stateless. Each JSON-RPC message is a POST to the endpoint; responses are JSON. No session ID is issued and GET returns 405.
Required headers
Content-Type: application/json, Accept: application/json, text/event-stream, Authorization: Bearer <access token>
Capabilities
tools only (no resources, prompts or sampling)
Batching
JSON-RPC batches are not supported (-32600)

Authentication

The connector is an OAuth 2.1 protected resource, following the MCP authorization specification. Users sign in once when they enable the connector; no Argos account is needed.

Discovery
An unauthenticated request receives 401 with WWW-Authenticate: Bearer resource_metadata="…" pointing to the protected resource metadata (RFC 9728).

Flow
Authorization code with PKCE (S256). Send the resource parameter (RFC 8707) set to the MCP endpoint.
Client registration
Client ID Metadata Documents and Dynamic Client Registration
Scopes
None required by the connector. openid offline_access may be requested for refresh tokens.
Token checks
Signed JWT access tokens are validated for signature, issuer, audience (must equal the MCP endpoint), expiry and not-before. Invalid or expired tokens get 401. Tokens are never forwarded to Argos.

Field rules

  • Prices are numbers in GBP. A missing price is null, never 0.
  • URLs are Argos product pages on argos.co.uk only.
  • Descriptions are converted from Argos's HTML to plain text. Markup and scripts are removed; safety warnings, age guidance and dimensions are kept.
  • Promotions: the badge code is passed through exactly as Argos supplies it. label is null: no discount or offer is inferred from the code.
  • totalCount is the total Argos reports, or null if it doesn't report one.
  • No stock, availability, delivery or rating information is provided.

Limits

  • Per user: 60 requests per minute. Overall: 600 per minute per server instance.
  • search: query up to 200 characters; limit 1–50 (default 20).
  • getProducts: one product ID per call (letters and digits, up to 20 characters).
  • Requests time out after about 15 seconds if Argos does not respond.

Data & privacy

  • Sent to Argos: only the search text and limit, or the product ID. No user identity, token or personal data.
  • Stored: nothing. There is no database, and results are not cached.
  • Logged: request metadata only (time, status, duration, tool name, a one-way hash of the user ID). Search text, tokens and cookies are never logged.
  • Sign-in: handled by WorkOS AuthKit; the connector only verifies the resulting token.
  • Availability: UK catalogue, prices in GBP.

Testing

The connector playground runs live endpoint checks, signs in with the same OAuth flow, and lets you call both tools.

  1. Open the playground. All endpoint checks should pass.
  2. Sign in (create an account with any email address).
  3. search for “cordless kettle”: expect typed products with GBP prices.
  4. getProducts for 8444015: expect a plain-text description and a promotion code with no label.
  5. getProducts for 0000000: expect an error result (product not found).
  6. Send a request without a token: expect HTTP 401.
